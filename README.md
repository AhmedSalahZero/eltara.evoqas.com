# El Tara / التارة

**Every trip counted — كل مشوار محسوب**

Fleet and trip-finance platform for Egyptian heavy-transport companies: an office portal, a client portal,
an offline-capable Driver App and a platform admin area, built for 500 companies and 20,000 users.

- **Set up and run:** [docs/SETUP.md](docs/SETUP.md)
- **All documentation:** [docs/README.md](docs/README.md)

Laravel 12 · PHP 8.4 · Vue 3 · Inertia 2 · Tailwind CSS 4 · Vite 7 · PWA (Workbox + IndexedDB) · MySQL 8
